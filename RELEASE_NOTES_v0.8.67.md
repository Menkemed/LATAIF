# LATAIF v0.8.67

Improvements from the first live test of New Purchase, and one name for every item.

- **One display name everywhere:** every item is named the same way in the collection, search,
  purchases, invoices, offers, consignments, the partner card, PDFs and on the phone. With a
  brand/model it is shown as before (e.g. "Rolex Datejust 36"); without one the name is built from
  the item's details, e.g. "Ring · Baguette Diamond · 18K Yellow · 3.10 g".
- **Gold-Diamond Jewellery without brand and model:** these fields are no longer asked for in any
  form (desktop and phone: collection, consignment, purchase). Values that were already saved stay
  and can still be edited or cleared. Branded Gold Jewelry, watches and all other categories are
  unchanged.
- **AI Identify for gold:** no brand or model for Gold-Diamond Jewellery any more — the piece type
  (Ring, Pendant, …) goes into Item Type.
- **Automatic SKU for purchases:** a new item bought through a purchase (desktop or phone) gets a
  SKU from the same counter as the collection when none is typed.
- **ID photo for a new person** in New Purchase on the phone (optional, like repair and
  consignment).
- **Phone:** the old "Purchase Photo" mode is removed — New Purchase replaces it. The desktop
  Purchase Inbox stays for existing entries. A booked purchase opens for viewing only, without a
  "New purchase" button.

Update the main computer first, then the second computer. No data is changed by the update.
