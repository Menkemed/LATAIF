# LATAIF v0.8.74

- **Second computer — payments on the invoice page:** "PAID" can be opened again on the second
  computer and lists the invoice's payments (date, method, note, amount), exactly as on the main
  computer. "Manage payments" is available there too. The list is read from the main computer and
  updates right after a payment is recorded or corrected.

Update the main computer first, then the second computer. No existing data is changed.
