# LATAIF v0.8.63

Confirmation prompts in the app's own design.

- **"Are you sure …?" prompts** now open as a dialog in the LATAIF design instead of the Windows
  message box: the question, the details below, Cancel and OK. Esc, Cancel or a click beside the
  dialog mean No — Esc closes only the prompt, not the window underneath.
- **Settle sale** opens its own dialog with the breakdown: net sale − cost − card fee = profit,
  then the partner's and LATAIF's share. For a correction it also shows what was settled so far
  and the difference booked now. Nothing is booked until "Settle".
- **Partners page:** each sale shows the invoice, its status and the button on one line, and the
  figures in labelled columns — net sale, cost, card fee, profit, partner, LATAIF, released.

Update the main computer first, then the second computer. No data is changed by the update.
